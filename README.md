# Concesionaria - Sistema de Gestión y Venta de Vehículos

Proyecto desarrollado con .NET 10 (C#), SQL Server y Vue.js 3, aplicando Clean Architecture y diseño PWA.

## Requisitos Previos (System Requirements)
Para clonar y ejecutar este proyecto localmente, asegúrate de tener instalado:
* [.NET 10.0 SDK](https://dotnet.microsoft.com/)
* [Node.js](https://nodejs.org/) (versión 18+ recomendada)
* [SQL Server](https://www.microsoft.com/es-es/sql-server/sql-server-downloads) y [SQL Server Management Studio (SSMS)](https://learn.microsoft.com/es-es/sql/ssms/download-sql-server-management-studio-ssms)

## Estructura del Repositorio
* `/backend`: API REST construida con ASP.NET Core (.NET 10).
* `/frontend`: Aplicación cliente construida con Vue 3 y Vite.
